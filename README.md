# Hopsland – Webdesign-Konzept (Portfolio-Projekt)

Responsive Website für einen **fiktiven** Indoor-Spielplatz, gebaut mit PHP-Includes, Bootstrap 5 und Sass.
Entstanden als Gruppenprojekt von Daniel Akinschin, Fabian Weber und Luisa Klaschka.

> Hopsland ist kein echtes Unternehmen. Alle Bilder sind selbst generierte Platzhalter,
> Preise, Zeiten und Kontaktdaten sind erfunden. Formulare senden keine Daten.

## Lokal starten

```bash
php -S localhost:8000
```

## Vor dem Veröffentlichen

1. `config.php`: Anschrift und E-Mail für Impressum & Datenschutz eintragen.
2. Optional eigene Bilder einsetzen (gleiche Dateinamen in `img/`), z. B. von Unsplash oder Pexels.
   Keine Fotos oder Logos realer Firmen verwenden.

Die Seite ist per `robots.txt`, `<meta name="robots">` und `X-Robots-Tag` von Suchmaschinen ausgeschlossen.
